# Tools System

Updated: 2026-09-25. Operational, publishing, research and assistant tools.

- `runtime_start_system`, `runtime_reset_system`: process lifecycle and explicit clean experiments.
- `runtime_database_system`: SQLite status, compatibility parity, deliberate imports/exports.
- Backup: external workspace tool `~/workspace_tools/backup/run.sh`.
- `diagnostics`, `analytics_system`: code/runtime/frontend checks and analytical reports.
- Publishing: external `~/workspace_tools/site_publish/run.sh`; project-owned `sitemap_system` and `news_generation_system` supply site assets.
- `research`: immutable-input experiments and replay; not automatically deployed strategy.
- `telegram_bot_system`: inbound commands and notifications.
- Internal assistant: external `~/workspace_tools/ai_assistant/run.sh`; project integration is documented in `../docs/system/ai_assistant.md`.
- `video_reels`: generated social video artifacts.

Tools may orchestrate strategy services; trading policy belongs to Spot/Futures/Hedge. Logs/reports go under runtime/logs and runtime/artifacts. Public content JSON is deliberately generated by the news pipeline; trading JSON is export/research material.

See [runbook](../docs/operations/runbook.md), [diagnostics](diagnostics/diagnostics_tool.md), [SEO/publishing](../docs/product/seo_and_publishing.md) and [research status](../docs/trading/strategy_research.md).
